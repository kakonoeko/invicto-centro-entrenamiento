# Invicto Centro de Entrenamiento

Web estática de Invicto, A Coruña, adaptada a móvil y ordenador.

## Abrir la web

Descarga `index.html` y ábrelo en un navegador. El logo, las fotografías, los estilos y el código están incluidos en el propio archivo.

## Contenido

- Actividades y sesiones de 30 y 60 minutos.
- Tarifas mensuales para 1, 2, 3 y 4 días por semana.
- Grupos de hasta 6 personas y sesión de prueba gratis.
- Contacto directo por WhatsApp al +34 610 39 89 55.
- Instagram: @invictoentrenamiento.

## Actualizar

Edita `index.html` y guarda los cambios en un commit. Conserva una copia antes de hacer cambios.

## Publicación

Este repositorio conserva el código. GitHub Pages no está activado.
